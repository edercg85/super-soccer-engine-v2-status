# Super Soccer V2 — status público

Site estático sanitizado. Gerado da fonte estruturada local por allowlist; o gerador e a fonte privada não são publicados. Execução técnica e aceite funcional são estados distintos; o MVP não está aceito.

## Atualização

Uma nova publicação exige gerar e validar novamente o site no worktree autorizado, revisar o allowlist e copiar somente os arquivos publicados para este repositório dedicado. O workflow valida o conteúdo e publica pelo GitHub Pages após push em `main`. Não inclua evidências brutas, caminhos locais, fingerprints internos, fontes do motor ou artefatos binários. A única exceção nesta publicação são os dois visualizadores autocontidos em `replays/`, preparados para avaliação humana e sem dados de build privados.
